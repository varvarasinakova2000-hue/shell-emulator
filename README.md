# Эмулятор UNIX-оболочки (вариант 25)

## Общее описание

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом
на Python + Tkinter. Окно состоит из области вывода, поля ввода команды
и кнопки «Enter». Заголовок окна строится по реальным данным ОС:
`Эмулятор - [username@hostname]`.

Реализованные этапы:

- **этап 1 (REPL)** — диалог с пользователем, команды-заглушки;
- **этап 2 (конфигурация)** — параметры командной строки
  и стартовый скрипт.

## Структура

```
src/main.py            — исходный код эмулятора
tests/test_main.py     — тесты
scripts/start.txt      — стартовый скрипт эмулятора (с ошибочными строками)
scripts/exit.txt       — стартовый скрипт с командой exit
scripts/test_params.*  — скрипты ОС: запуск со всеми вариантами параметров
scripts/test_errors.*  — скрипты ОС: ошибки в параметрах
run.bat, run.sh        — скрипты запуска
```

## Функции и команды

| Команда | Описание |
|---------|----------|
| `ls [аргументы]` | заглушка: выводит имя команды и аргументы |
| `cd [аргументы]` | заглушка: выводит имя команды и аргументы |
| `exit` | закрывает эмулятор |

Ввод разделяется на команду и аргументы по пробелам.

Обработка ошибок:

- неизвестная команда — `shell-emulator: command not found: <имя>`;
- `exit` с аргументами — `shell-emulator: exit: too many arguments`;
- стартовый скрипт не найден или не читается —
  `shell-emulator: не удалось прочитать скрипт <путь>: <причина>`,
  где причина — «файл не найден», «файл не в кодировке UTF-8»
  или системное описание ошибки;
- неизвестный параметр командной строки или параметр без значения —
  сообщение argparse и завершение с кодом 2.

Функции в `src/main.py`:

- `get_user_and_host()` — имя пользователя и компьютера из ОС;
- `parse_args(argv)` — разбор параметров командной строки;
- `read_script(path)` — чтение стартового скрипта;
- `parse_command(line)` — разбор строки на команду и аргументы;
- `execute(command, args)` — выполнение команды, возвращает текст вывода;
- `TerminalEmulator` — окно эмулятора.

## Настройки

Параметры командной строки:

| Параметр | Описание |
|----------|----------|
| `--vfs PATH` | путь к физическому расположению VFS (используется с этапа 3) |
| `--script PATH` | путь к стартовому скрипту |
| `-h`, `--help` | справка по параметрам |

При запуске эмулятор выводит в окно все заданные параметры
(отладочный вывод).

Стартовый скрипт — текстовый файл в UTF-8, по одной команде в строке.
Пустые строки и строки, начинающиеся с `#`, пропускаются. Команды
выполняются по очереди, на экране видны и команда, и её вывод.
Ошибочная строка выводит сообщение об ошибке, после чего выполнение
продолжается со следующей строки. Команда `exit` в скрипте закрывает
эмулятор.

## Сборка, запуск и тесты

Требуется Python 3 (Tkinter входит в стандартную поставку).
Сборка не требуется, сторонние зависимости не используются.

Запуск эмулятора:

```
run.bat [--vfs PATH] [--script PATH]       # Windows
./run.sh [--vfs PATH] [--script PATH]      # Linux / macOS
```

Проверка параметров командной строки (скрипты ОС):

```
scripts\test_params.bat     # все варианты параметров
scripts\test_errors.bat     # ошибочные параметры
```

Для Linux / macOS — `scripts/test_params.sh` и `scripts/test_errors.sh`.

Запуск тестов:

```
python -m unittest discover -s tests
```

## Пример использования

Интерактивный режим:

```
User@DESKTOP:~$ ls
Вызвана заглушка команды: ls
Переданные аргументы: [нет аргументов]

User@DESKTOP:~$ cd /home user
Вызвана заглушка команды: cd
Переданные аргументы: /home user

User@DESKTOP:~$ foo
shell-emulator: command not found: foo

User@DESKTOP:~$ exit 1
shell-emulator: exit: too many arguments

User@DESKTOP:~$ exit
```

Запуск со стартовым скриптом — `run.bat --vfs vfs --script scripts\start.txt`:

```
Параметры запуска:
  VFS: vfs
  Стартовый скрипт: scripts\start.txt

User@DESKTOP:~$ ls
Вызвана заглушка команды: ls
Переданные аргументы: [нет аргументов]

User@DESKTOP:~$ unknown_command arg
shell-emulator: command not found: unknown_command

User@DESKTOP:~$ cd ..
Вызвана заглушка команды: cd
Переданные аргументы: ..
```
